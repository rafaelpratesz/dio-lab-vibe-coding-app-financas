🧠 Prompt Final (PRD – Product Requirements Document)

Título: App de Organização de Finanças Pessoais com IA – SmartBudget AI

Objetivo do Produto:
Criar um aplicativo moderno, intuitivo e minimalista que ajude usuários a organizar suas finanças pessoais de forma automática usando IA.
O app deve usar inteligência artificial para:

Classificar gastos automaticamente

Prever despesas futuras

Criar metas financeiras personalizadas

Gerar relatórios semanais

Sugerir cortes de gastos com base em hábitos do usuário

Público-alvo:
Pessoas que desejam ter controle financeiro de forma simples, rápida e automatizada, mesmo sem conhecimento de economia.

Funcionalidades Principais:

Dashboard Inteligente

Gráficos de entradas e saídas

Insights gerados por IA

Notificações financeiras importantes

Classificação Automática de Gastos (via IA)

Leitura de extratos bancários

Identificação automática de categorias (Alimentação, Moradia, Lazer, Transportes etc.)

Correção automática com aprendizado contínuo

Planejamento Financeiro

Criação de metas (ex.: viagem, reserva de emergência, compras)

Acompanhamento de progresso

Recomendação personalizada de economia semanal

Previsão de Gastos (Machine Learning)

Previsão baseada no comportamento do usuário

Alertas de gastos acima do normal

Sugestões de economia

Relatórios Semanais e Mensais

Gráficos

Resumo inteligente

Dicas personalizadas

Requisitos Técnicos:

Interface moderna baseada em React/Next.js ou Flutter

Backend em Node.js (pode usar Firebase)

IA integrada usando API do OpenAI ou modelos locais

Banco de dados para armazenar transações

Login com Google/Apple

Design minimalista e responsivo

🔧 Instruções para o Copilot/Lovable:

Construa um aplicativo chamado “SmartBudget AI”, com as funcionalidades listadas acima.
Use código limpo, organizado e componentizado.
Utilize boas práticas de acessibilidade.
Gere telas modernas e com visual amigável.
Implemente IA para classificação e previsões financeiras.
Inclua modelos de tela para dashboard, metas, relatórios e perfil.
